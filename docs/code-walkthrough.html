What happens when you press Return

One command, two possible paths. main() reads the flags and sends the run down the export path or the prune path.

      Level 7 · Mental model

      The conservation lab

      Think of the program as a lab that looks after one irreplaceable archive: Safari's Bookmarks.plist.

      The core rule of the lab is that nobody works on the original. Everything happens on a copy, the copy is checked against the request, and the original is only replaced while the building is closed (Safari quit) and nobody else has touched it since the copy was made.

        Pure or side-effecting? Sort every function

        A useful first pass on any file: mark which functions only compute (pure: same input, same output, touches nothing) and which reach out to the world (files, processes, the clock). Pure functions are easy to test and safe to call. Side effects are where bugs and danger live, so read those most carefully.
